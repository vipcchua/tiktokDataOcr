# 抖音数据分析 · tiktokDataOcr

从抖音作品数据截图中提取标题、发布时间、流量指标和作品状态，整理成可编辑、可复制的表格。单张截图包含多条作品时，网页会尝试自动拆分，每条作品占一行。图片在浏览器内处理。

## 在线使用

打开 [抖音数据分析](https://tiktokdataocr.pages.dev/)。首次加载中文 OCR 模型需要一定时间，页面会显示下载进度。看到「OCR 模型已就绪 ✓」后即可开始识别。再次打开时，浏览器会尝试复用已下载的模型。

### 1. 添加截图

- 点击「选择图片（可多选）」，或把图片拖进截图区域。
- 如果图片已复制到剪贴板，可以按 `Ctrl+V`，也可以点击「粘贴图片」。
- 如果需要在表格或 Excel 中带上原截图，请在识别前勾选「添加作品信息」里的「保留截图」。该选项默认关闭，关闭后会释放当前保留的截图，文字结果仍在。

识别支持手机作品详情、电脑端数据页和横排作品卡片。结果会逐张加入表格。遇到重复标题时，网页会集中列出重复项，勾选后可「添加选中」或「替换选中」。替换会更新原行的识别数据和截图，保留原来的账号分配与手填链接。

### 2. 整理识别结果

- **编辑**：在默认打开的「Excel版本」中双击数据单元格，按 Enter 保存。也可以切到「识别结果」直接修改。发布时间统一显示为 `2026-11-21 13:11`。作品「链接」列可手动填写。
- **排序和删除**：按住作品行上下拖动调整顺序，序号会自动重排。左右拖动可查看其他列。每行最右侧的垃圾桶用于删除该条作品。
- **管理账号**：在「账号预设」添加账号名字、ID、主页链接和粉丝数，保存后可逐行分配，也可点击多条作品行后批量分配。勾选默认账号后，未分配的作品和新识别的作品会使用该账号。
- **选择列**：在「信息选定」勾选需要显示和导出的字段，可调整列顺序或恢复默认预设。账号预设和列设置会保存在当前浏览器。

识别不确定的字段可能留空，作品状态无法判断时显示「未知」。遇到模糊、裁切或压缩过的截图，建议对照原图核对数字。

### 3. 复制或下载 Excel

- 点击「复制整表」，可粘贴到 Excel。
- 在「Excel版本」点击「下载 Excel」，可保存 `.xlsx`。开启「保留截图」后，保留的图片会放在相应作品行的最后一列。需要图片时可直接下载工作簿。
- 勾选「合并连续同账号单元格」，可合并相邻同账号行的账号信息。
- 勾选「数据分析保留」，下载时会把统计放到工作簿的第二张工作表。

页面底部的「数据分析」会随结果更新，包含作品数、发布账号数、流量合计、平均完播率和各作品的播放量占比饼图。

## Windows 本地启动

安装 Node.js 24 后，双击项目中的 `start-ocr.bat`。首次启动会安装依赖，然后用默认浏览器打开 [http://127.0.0.1:8087/](http://127.0.0.1:8087/)。使用时保持启动窗口开着。

也可以在项目目录运行：

```sh
npm ci
npm run dev
```
